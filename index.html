Notes

How to read these figures

Research only

These figures are for research. They are not official statistics and should not be quoted as such.

Approval rates

Each rate comes from one council's own planning register, using decided applications only. It is not a statewide figure.

Counts differ by stage

Every stage counts a different type of record: planning applications, properties resolved, building events, candidate pairs and matched records. Only councils set up for a stage are counted.

No statewide total yet

A statewide planning dataset (PPARS) is still not available to us, so we do not publish statewide planning figures.

Provisional rates

Some councils have not published many decisions yet. Their approval rates are provisional and are marked with an asterisk.

Source files

We keep a checksum and retrieval record for every source file used. Details are in the project's documentation.
